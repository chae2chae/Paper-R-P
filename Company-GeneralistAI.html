03

Method — 어떤 기술인가?

회사는 자신을 VLA도 World Model도 아닌 "physical foundation model"로 정의한다. 외부 분류 트리 위에 올려놓고 보면, "VLM 없이 처음부터 학습한 엔드투엔드 행동 FM"에 가장 가깝다.

① 분류 — VLA vs World Model vs Physical FM

사전학습된 VLM 위에 액션 헤드를 얹는가? 명시적 dynamics rollout이 있는가? 두 질문의 답으로 갈라진다.

② 아키텍처 — Harmonic Reasoning

센싱 토큰과 액션 토큰을 인터리브된 단일 시퀀스로 흘림. System1/2 분리(느린 사고 + 빠른 행동) 거부. "physics doesn't stop" — 생각하기와 행동하기의 시간적 분리를 없애는 것이 핵심 베팅.

일반 VLA: 관측 → N개 액션 청크 일괄 예측 → 실행 → 다음 관측. 청크 사이 latency / jitter가 발생.
Harmonic Reasoning: 두 스트림을 같은 어텐션에서 동시에 흘림. 청크 사이의 단절이 구조적으로 사라진다고 주장.

③ 학습 파이프라인 (4단계)

공개된 단편 + 외부 보도 + LLM 표준 레시피 조합 기반 추정.

STAGE 1

Massive Pretrain

인간 wearable 50만h · 로봇 데이터 0 · next-action 예측 (validation MSE)

STAGE 2

Robot Adaptation

task당 ~1h 로봇 데이터 · 후학습 step 수천 (cross-embodiment swap)

STAGE 3

RL + Human Guidance

"theoretical RL" + multimodal human guidance · reverse-KL로 SFT/RL 분리

STAGE 4

Real-time Inference

Harmonic Reasoning + paged attention 커스텀 커널 · 실시간 스트림 출력

Scaling Law in Robotics

Kaplan 2020 LLM과 동일한 functional form $L(D)=(D_c/D)^{\alpha_D}$. 그러나 모델 사이즈에서 phase transition이 관측되며, 그 임계가 7B 부근. 로봇 FM에서 처음 수립된 스케일링 법칙으로 평가됨.

Phase Transition at 7B Parameters

로그 스케일에서 본 다양한 모델 사이즈의 학습 거동 (정성적 재현).

Below 7B: 가중치가 다양한 데이터를 흡수 못하고 굳음 ("ossification"). 6B에서 멀티태스크 학습이 시작될 뿐.
7B+: 사전학습 내재화 → 수천 step 후학습만으로 새 task 전이. 10B+까지 검증.

해석: 물리 commonsense 학습은 언어보다 더 높은 compute threshold가 필요하다는 가설. 과거 로봇 연구가 이를 못 본 이유는 (a) high data regime 부재, (b) 충분히 큰 모델 부재.

My Takeaway

  • "데이터 파이프라인이 모델보다 먼저" — wearable 기반 인간 시연 데이터 수집을 회사의 1번 자산으로 본 점. 시뮬레이션·텔레op에만 의존하지 않는 실세계 데이터 인프라 설계 관점.
  • VLA → physical-first FM 흐름 — 향후 로봇 FM 논문 follow 시 "pretrained VLM fine-tune" vs "from-scratch physical FM" 두 트랙으로 분리 추적할 가치.
  • 하드웨어 미니멀리즘 — 휴머노이드 폼팩터 없이 산업용 암 + 그리퍼만으로 contact-rich 작업 시연. "지능이 곧 차별화"라는 가설을 가장 강하게 베팅 중.
  • Scaling laws in robotics — Kaplan 2020 스타일을 로봇에 적용한 보기 드문 자료. 7B phase transition은 향후 검증 포인트.
  • Improvisational Intelligence — RL의 exploration / recovery와 연결되는 흥미로운 관점. 별도 모듈 없이 단일 모델에서 emergence라고 주장.
  • 1시간 로봇 데이터로 99% 성공률 — 극단적 data efficiency가 핵심 경쟁력. dexterity 중심 manipulation 연구 방향과 직접 연결.
