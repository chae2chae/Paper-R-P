Product — π 시리즈

π0 (2024-10)

첫 generalist policy. VLM(PaliGemma) + flow matching action expert, 50Hz 실시간 액션. 2025-02 오픈소스 공개.

openpi Cross-embodiment

π0-FAST

Autoregressive action tokenizer로 학습 5× 가속.

π0.5

Open-world generalization. Knowledge insulation + 새 환경 일반화. Egocentric wearable 인간 데이터와 co-training.

π0.7 (2026-04)

Compositional generalization. 학습 데이터에 없던 task도 단편 데이터 + 웹 사전학습으로 합성. 에어프라이어 요리, 커피, 빨래, 박스 조립, 기어 회전 등.

타겟 폼팩터: 휴머노이드 / 모바일 매니퓰레이터 / 단·양팔 산업로봇 모두. 소프트웨어 우선 — 어떤 로봇에든 들어가는 brain. 하드웨어 수직통합 X.

05

My Takeaway

  • VLM + flow matching = 현재 VLA 표준 레시피 — π0 논문이 사실상 reference design. RT-2 이후 "VLM에 flow matching action head 붙임"이 메인스트림. VLA 코드 베이스로 openpi 사용이 빠른 시작점.
  • Generalist vs PI 비교축 — 데이터는 둘 다 텔레op + 인간 wearable이나 비중·위상이 다름. 모델 출발점(VLM 위에 쌓기 vs scratch)과 공개 전략에서 갈림. 두 회사 비교만으로 "VLA 다음 5년"의 주요 분기점이 잘 보임.
  • 학계 듀얼 어피일리에이션 — Levine·Finn이 교수직을 유지하며 창업. 학생·논문 파이프라인이 회사 자산. 내 커리어 모델로도 참고할 만함.
  • Compositional generalization (π0.7) — 단편 데이터로 새 task 합성. 로봇 데이터 효율의 핵심 지표. "한 task당 N시간" sample efficiency + compositional eval 두 축으로 향후 비교.
  • 밸류에이션 곡선 — 18개월 만에 $2B → $5.6B → $11B 예상. 로봇 FM 분야 자본 집중도가 LLM 초기와 유사.
